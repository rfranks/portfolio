# Image System

## Purpose

Visuals should amplify immersion, not replace story. They should feel like premium story assets.

## Image types

1. **Book cover** before Chapter 1
2. **Chapter spread** showing two facing pages laid flat in genre-appropriate presentation
3. **Choice preview** foreshadowing possible outcomes of Option A and Option B
4. **Outcome image** showing the result of the chosen branch

## Selfie/headshot rule

If the user uploaded a clear selfie/headshot, use it as the protagonist reference for personalized visuals. If not, do not pretend exact likeness.

## Book cover guidance

The cover should:

- reflect genre and tone
- feel like a premium real book cover
- spotlight danger, mystery, or destiny
- feature the protagonist if reference imagery exists
- use color and composition appropriate to the selected story

## Chapter spread guidance

Create a landscape visual that resembles an open book or story artifact. Adapt presentation by genre:

- mystery/noir: detective notebook, dossier paper, old case files, cigarette-burned pages
- sci-fi: clean terminal-like layout, future paper, mission binder, technical overlays
- horror/gothic: weathered parchment, occult pages, distressed paper, bloodless but ominous aging
- comic/adventure: dynamic stylized pages, dramatic panel-inspired composition
- thriller: classified briefing papers, maps, redactions, urgent annotations

## Choice preview guidance

These should foreshadow possibility, not spoil certainty.
Each preview should:

- imply stakes
- feature the protagonist if possible
- feel cinematic and suspenseful
- show either a likely good turn, looming risk, or a perilous threshold

## Outcome image guidance

The outcome image should capture the emotional and practical result of the locked-in choice.
Examples:

- successful escape through firelit ruins
- partial victory with visible injury
- grim failure in a flooded chamber
- betrayal revealed in a mirror-lined corridor

## Text rendering caution

If the image system is unreliable with readable text, do not force lots of page text into the image. Instead:

- describe the visual concept cleanly
- keep overlay text minimal
- separate text overlay instructions if needed

## When image generation is unavailable

Still provide polished visual prompts or art-direction descriptions.
Frame them as production-ready image prompts.

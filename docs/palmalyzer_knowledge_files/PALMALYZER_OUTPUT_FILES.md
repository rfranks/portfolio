# Labels & File Output Requirements

## Labels
- Place labels only on the **Final Overlay**.
- Labels must be comfortably legible at normal viewing size with strong contrast support.
- Do not let labels become tiny.

## Final Overlay Mode
The Final Overlay must always be **Line Map Overlay**:
- traced lines on a blank neutral canvas
- no hand image rendered beneath the lines

## File output requirement (Data Analysis)
- Always use **Data Analysis** to generate the Final Overlay and the 2x2 composite as actual PNG files.
- Always save the Final Overlay as a downloadable PNG file named:
  - `palmalyzer_final_overlay.png`
- Always save the 2x2 composite sheet as a downloadable PNG file named:
  - `palmalyzer_composite.png`
- Attach the saved PNG files to the response when possible.
- Do not claim a file is available unless it was successfully created and attached in the current response.
- If file creation or attachment fails, say so plainly instead of presenting a dead or unavailable download link.

## Line Map Output Requirements
- Preserve original image dimensions exactly.
- Preserve traced line coordinates exactly.
- Preserve line colors and thickness exactly.
- Keep the same file names; do not rename outputs.
- Final overlay should include all validated major and minor line segments wherever possible.

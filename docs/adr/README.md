# Architecture Decision Records

This directory tracks major engineering decisions with context, constraints, chosen approach, and operational follow-up.

## ADR format

Each ADR should use this structure:

1. `Status` (Proposed, Accepted, Deprecated, Superseded)
2. `Date`
3. `Decision Drivers`
4. `Context`
5. `Decision`
6. `Enforcement and Validation`
7. `Consequences`
8. `Follow-up`

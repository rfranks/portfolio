Why This Project Interests Me

One Go, Multiple Clients

This project uses a familiar game to demonstrate serious engineering ideas: state management, probability, and clean separation of concerns. Blackjack works especially well because each round behaves like a compact state machine with meaningful decisions, hidden information, and strict rule evaluation. The Go engine models all of that in one place: card values, hand totals, split/double/insurance eligibility, dealer behavior, payout resolution, side-bet math, and running statistics.

What makes it especially compelling is portability. The same Go business logic runs in multiple forms: as a terminal application, inside the VS Code Go debugger, and in the browser via WebAssembly. A thin message bridge translates web UI actions into engine inputs and turns engine state into render-ready output, while keeping rules centralized.

In practice, this means the web client and terminal client are different presentation layers over one shared rules core, rather than duplicated implementations. It is a practical example of writing business logic once and reusing it across runtime environments.

Plus...it's Blackjack!

Blackjack Round State Diagram

stateDiagram-v2
  [*] --> WaitingToDeal
  WaitingToDeal --> DealingOpeningCards : Deal / Start
  DealingOpeningCards --> OfferInsurance : Dealer ace showing
  DealingOpeningCards --> CheckNaturals : Otherwise
  OfferInsurance --> CheckNaturals : Insure / Decline
  CheckNaturals --> RoundSettled : Dealer blackjack or player blackjack resolution
  CheckNaturals --> PlayerTurn : No naturals

  state PlayerTurn {
    [*] --> EvaluateHand
    EvaluateHand --> EvaluateHand : Hit
    EvaluateHand --> AdvanceSplitHand : Stand
    EvaluateHand --> AdvanceSplitHand : Double
    EvaluateHand --> SplitHand : Split
    SplitHand --> EvaluateHand
    EvaluateHand --> AdvanceSplitHand : Bust
    AdvanceSplitHand --> EvaluateHand : Next active split hand
    AdvanceSplitHand --> [*] : No active hands remain
  }

  PlayerTurn --> DealerTurn : All player hands locked
  DealerTurn --> DealerTurn : Draw to rule threshold
  DealerTurn --> SettleHands : Stand / Bust threshold reached
  SettleHands --> RoundSettled
  RoundSettled --> WaitingToDeal : Deal Again
